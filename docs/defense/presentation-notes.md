# Notas de presentación

## Mensaje principal

FlacoFitness es un proyecto académico final orientado a resolver la gestión operativa de un gimnasio con una arquitectura clara, mantenible y preparada para evolucionar.

## Puntos clave para exponer

- Elección de arquitectura monolítica MVC por simplicidad y coherencia académica
- Uso de Spring Boot para acelerar desarrollo backend y estructurar capas
- Uso de Thymeleaf y Bootstrap para una interfaz web integrada con el backend
- Preparación del proyecto para dockerización y despliegue reproducible
- Inclusión de documentación viva en el repositorio para trabajo asistido por agentes

## Demostración sugerida

1. Mostrar la estructura del repositorio
2. Explicar las capas del sistema
3. Enseñar la documentación viva y el roadmap
4. Navegar por las vistas base
5. Presentar la estrategia de crecimiento del proyecto
