# Project Overview

## Nombre del proyecto

FlacoFitness

## Objetivo general

Desarrollar una aplicación web académica para la gestión integral de un gimnasio, cubriendo administración de usuarios, planes, rutinas, asistencias y pagos mediante una arquitectura monolítica MVC.

## Stack tecnológico

- Java 17
- Spring Boot
- Spring Data JPA
- Thymeleaf
- Bootstrap 5
- MySQL
- Maven
- Docker / Docker Compose

## Alcance inicial

- Estructurar el repositorio para crecimiento ordenado
- Definir capas MVC y convención de paquetes
- Preparar la base documental para trabajo asistido por agentes
- Dejar configurado el proyecto para desarrollo local y futura dockerización
- Crear las vistas base para módulos principales sin lógica de negocio completa

## Público objetivo

- Profesorado evaluador del proyecto académico
- Estudiantes desarrolladores del sistema
- Personal administrativo básico de un gimnasio o centro fitness
